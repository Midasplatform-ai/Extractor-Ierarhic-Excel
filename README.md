📊 Extractor Ierarhic Excel

Un tool web care permite încărcarea unui fișier Excel și generarea automată de fișiere separate pe nivele ierarhice.

📝 Descriere

Această aplicație web procesează un fișier Excel (.xlsx / .xls) și construiește structuri ierarhice pornind de la relația Coordonator → Nume Prenume.
Pentru fiecare coordonator de nivel superior, aplicația generează automat:

lista completă a subordonaților (toate nivelurile)

numărul total de persoane din ierarhie

fișier Excel separat pentru fiecare coordonator

Totul se execută direct în browser, fără server, folosind biblioteca xlsx.js.
